# PÓS TECH Arquitetura de Sistemas .NET

Repositório com os projetos, estudos práticos e entregas desenvolvidos ao longo da pós-graduação **PÓS TECH Arquitetura de Sistemas .NET**, da **FIAP + Alura**.

O objetivo deste espaço é centralizar a evolução técnica do curso, reunindo implementações em **.NET**, **ASP.NET**, **microsserviços**, **mensageria**, **containers**, **Kubernetes**, **cloud**, **qualidade de software**, **segurança** e **Inteligência Artificial aplicada ao ecossistema .NET**.

## Sobre o curso

De acordo com a página oficial da FIAP, a formação tem **360 horas**, duração estimada de **10 meses** e abordagem **100% digital e hands-on**, com foco no desenvolvimento de sistemas backend com recursos da plataforma **.NET**, linguagem **ASP.NET** e serviços em nuvem, com destaque para **Azure**.

Ao longo da jornada, o curso aborda temas como:

- Arquitetura e qualidade de software
- Desenvolvimento de APIs com .NET
- Entity Framework Core
- Microsserviços e mensageria
- Docker e Kubernetes
- Serverless e API Gateway
- Monitoramento e observabilidade
- DevOps, CI/CD e cloud
- Segurança, LGPD e boas práticas
- Inteligência Artificial no ecossistema .NET

Fonte oficial do curso:
- [FIAP - PÓS TECH Arquitetura de Sistemas .NET](https://postech.fiap.com.br/curso/arquitetura-sistemas-net/)


## Trilhas e competências do curso

Com base no conteúdo oficial da FIAP, a jornada da pós está distribuída em 5 fases:

### Fase 1
- Arquitetura e Qualidade de Software
- DDD
- APIs com .NET
- Entity Framework Core
- Testes, TDD e BDD

### Fase 2
- Microsserviços
- Docker
- Kubernetes
- Mensageria e Event-Driven Architecture

### Fase 3
- Arquitetura de Software
- Serverless
- API Gateway
- Monitoramento, APM e observabilidade
- NoSQL, CQRS e Event Sourcing

### Fase 4
- Azure DevOps
- AWS
- GitHub Actions
- CI/CD
- Elasticsearch

### Fase 5
- Metodologias ágeis
- SOLID
- Privacidade de dados e LGPD
- Blazor e Razor
- Inteligência Artificial em .NET
